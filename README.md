# Программа для обновления информации товаров на Озон.

Программа обновляет ассортимент, количество и цены товаров на сайте Озон.

## Порядок действий программы

- Заходит в личный кабинет продавца на Озон.
- Скачивает полный список товаров и получает список их артикулов.
- Скачивает таблицу товаров с сайта Casio.
- Сопоставляет товары по количеству и загружает актуальные данные на площадку Озон.
- Создает список с ценами с сайта Casio, изменяет в нужный вид и также загружает на Озон.
